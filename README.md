# Pet Steps

**Контрольная работа №2:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

**Студент:** _впишите ФИО и группу_.

Pet Steps — учебный каталог услуг для владельцев питомцев: выгул, абонементы на прогулки, передержка, груминг и зооняня.

## Запуск

Откройте `index.html` в браузере. Bootstrap 5.3.8 и изображения хранятся в проекте. Для работы с сохранёнными данными используйте опубликованный сайт или локальный HTTP-сервер. Например, запустите в папке проекта `python3 -m http.server 8000` и откройте `http://localhost:8000`. Карта загружается из интернета. На страницах сначала подключается Bootstrap CSS, затем `css/custom.css`; внизу подключаются Bootstrap JS Bundle и `js/main.js`.

## Что взято из практических № 9–11

- № 9: баннер и блок преимуществ на сетке `container`, `row`, `col-*`, `g-*`; на главной карточки используют `col-12 col-md-6 col-lg-4`.
- № 10: разметка `navbar`, `card`, `btn`, `badge`, `modal`, `alert`, `accordion` и формы с `form-control`, `form-select`, `input-group`, `form-check`.
- № 11: локальное подключение Bootstrap, адаптивная вёрстка, проверка формы и описание проекта в README.

Самостоятельные доработки: четыре совместимых фильтра, одно модальное окно для разных карточек, выбор услуги по адресу страницы, хлебные крошки, закреплённое меню, якорные ссылки и кнопка «Наверх». Flexbox используется в меню и группах кнопок, CSS Grid — для ссылок на направления и параметров услуги.

## Пять новых функций

- Отзывы на главной. Добавление оценки и комментария, средний балл, удаление своего локального отзыва.
- Трекер на странице «Мой питомец». Сохранённые заявки, этапы услуги и отмена с освобождением времени.
- Календарь в форме заявки. Месяцы, даты на 90 дней вперёд, время по Москве, блокировка прошедшего и занятого времени. Длительность услуги учитывается при проверке пересечений.
- Паспорт питомца. Кличка, вид, порода, привычки и фото JPEG/PNG/WebP до 5 МБ. Фото сжимается, данные подставляются в новую заявку.
- Квиз на главной. Три вопроса, рекомендация одной из шести услуг и переход к записи. Для кошек предлагаются зооняня и передержка.

Данные хранятся в localStorage этого браузера и сохраняются после перезагрузки. Отзывы и занятость времени видны на этом устройстве. Трекер демонстрационный, его статусы переключаются кнопкой «Следующий этап». Для общей записи разных пользователей понадобится сервер. Контактные данные владельца в хранилище заявок не записываются.

Для проверки пройдите квиз, создайте паспорт с фото и оформите заявку на завтра. Откройте «Мой питомец», измените статус или отмените запись. Проверьте, что отмена освобождает время. На главной оставьте отзыв и обновите страницу.

## Как показать на защите

1. Откройте главную страницу и нажмите «Выгул» в разделе «Чем можем помочь». Каталог откроется с выбранным типом услуги.
2. Выберите «60 минут», «Групповой» и «Сокольники». Останется одна карточка. Нажмите «Подробнее», затем «Перейти к услуге».
3. Попробуйте отправить пустую заявку. Заполните поля, выберите дату и время, отметьте согласие. Появится сообщение об успешной проверке.
4. Откройте «Контакты». Раскройте вопрос про абонемент и попробуйте форму обратной связи.
5. Сузьте окно браузера: меню свернётся, карточки и поля формы перестроятся.

Заявки, отзывы и паспорт сохраняются в браузере. Серверная отправка и оплата не подключены. Специалисты, цены, статистика и фотоотчёт приведены для демонстрации. Адрес и телефон в подвале относятся к [кампусу РТУ МИРЭА](https://www.mirea.ru/sveden/common/).
