# Pet Steps

**Контрольная работа №2:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

**Студент:** _впишите ФИО и группу_.

Pet Steps — учебный каталог услуг для владельцев питомцев: выгул, абонементы на прогулки, передержка, груминг и зооняня.

## Запуск

Откройте `index.html` в браузере. Сервер, npm и интернет не нужны: Bootstrap 5.3.8 и изображения хранятся в проекте. На страницах сначала подключается Bootstrap CSS, затем `css/custom.css`; внизу подключаются Bootstrap JS Bundle и `js/main.js`.

## Структура

| Файл или папка | Что внутри |
| --- | --- |
| `index.html` | Главная: баннер, направления, популярные услуги, преимущества и статистика |
| `about.html` | О нас: описание Pet Steps и порядок записи |
| `catalog.html` | Карточки услуг, цены и фильтры |
| `product.html` | Подробности выбранной услуги, форма заявки и пример фотоотчёта |
| `contacts.html` | Контакты, форма обратной связи и частые вопросы |
| `order.html` | Переход к `product.html#booking`: по теме проекта заявка находится на странице услуги |
| `css/custom.css` | CSS-переменные, оформление и БЭМ-классы для элементов проекта |
| `js/main.js` | Фильтры, данные модального окна и услуг, проверка форм и кнопка «Наверх» |
| `images/` | Фотографии услуг и логотип |
| `vendor/bootstrap/` | Локальные файлы Bootstrap и лицензия |

## Что взято из практических № 9–11

- № 9: баннер и блок преимуществ на сетке `container`, `row`, `col-*`, `g-*`; на главной карточки используют `col-12 col-md-6 col-lg-4`.
- № 10: разметка `navbar`, `card`, `btn`, `badge`, `modal`, `alert`, `accordion` и формы с `form-control`, `form-select`, `input-group`, `form-check`.
- № 11: локальное подключение Bootstrap, адаптивная вёрстка, проверка формы и описание проекта в README.

Самостоятельные доработки: четыре совместимых фильтра, одно модальное окно для разных карточек, выбор услуги по адресу страницы, хлебные крошки, закреплённое меню, якорные ссылки и кнопка «Наверх». Flexbox используется в меню и группах кнопок, CSS Grid — для ссылок на направления и параметров услуги.

## Как показать на защите

1. Откройте главную страницу и нажмите «Выгул» в разделе «Чем можем помочь». Каталог откроется с выбранным типом услуги.
2. Выберите «60 минут», «Групповой» и «Сокольники». Останется одна карточка. Нажмите «Подробнее», затем «Перейти к услуге».
3. Попробуйте отправить пустую заявку. Заполните поля, выберите дату и время, отметьте согласие. Появится сообщение об успешной проверке.
4. Откройте «Контакты». Раскройте вопрос про абонемент и попробуйте форму обратной связи.
5. Сузьте окно браузера: меню свернётся, карточки и поля формы перестроятся.

Формы проверяют введённые данные в браузере. Серверной отправки, оплаты и хранения персональных данных нет. Специалисты, цены, статистика и фотоотчёт приведены для демонстрации. Адрес и телефон в подвале относятся к [кампусу РТУ МИРЭА](https://www.mirea.ru/sveden/common/).
